# Disposable WordPress checks

Use an isolated WordPress/PHP 8.2 container with a MariaDB 11.4 database named `toto_test`. Mount `toto-partner-booking` in `wp-content/plugins/toto-partner-booking`, readable by Apache. Do not run these tests on a real site.

`setup.php` installs a fresh test site, activates the plugin and creates random test-only credentials in `/tmp/toto-test-credentials.json` inside the container. It refuses another database name. Run it only on a new database. Then run `integration.php` in the same container. The test expects an empty plugin database and a loopback site address.

`race-worker.php 0` and `race-worker.php 1`, run simultaneously after the integration test, attempt to approve different pending requests for the last room. Exactly one must return 200 and the other 409. The worker uses `/tmp/toto-race.json`, generated by integration.php.

The real-browser check uses Python Playwright and system Chromium; copy the temporary credential JSON out of the container into `/tmp/toto-test-credentials.json` and run `browser.py`. Do not commit credentials. Test guest names and contacts are fictitious. Screenshot output contains only those test entries. No paid gateway or notification is exercised.
